# Kamba

Kamba é uma plataforma de serviços que aproxima clientes e profissionais.

## Estrutura atual

- `site/` — website institucional inicial
- `app/` — futura aplicação Flutter Android/iOS
- `backend/` — futura API Kamba
- `admin/` — futuro painel administrativo
- `docs/` — documentação do projeto

## Visão do produto

O cliente publica um pedido com serviço, localização, orçamento, data e descrição. Profissionais podem enviar propostas. O cliente escolhe uma proposta e o Kamba regista o contrato, permitindo acompanhar o serviço e avaliar a experiência.
